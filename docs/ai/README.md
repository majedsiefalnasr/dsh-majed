# Working evidence

The files in this folder are dated working evidence recorded while features were built (verification notes, parity matrices, owner test scripts, rename and release notes). They are not product documentation.

- Test counts and file/line references are historical; they describe the tree at the time of writing.
- Identifiers using the retired product name (`majed*`) are historical; current names use the `waycraft` prefix (see `rename-waycraft.md`).
- `current-work.md` is the live record of the current phase; start there.
