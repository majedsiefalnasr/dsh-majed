# Ticket #157 parity matrix: Skill manager vs `@michengai/dsh-skills-manager`

Reference: pinned read-only checkout `.scratch/dsh-skills-manager-reference/src` (v1.2.29, commit `49037a9`, 12,598 lines). Waycraft: branch `impl/157-parity-evidence` (base `4dfbf48` = #156). Spec: `docs/specs/skill-manager.md` (47 user stories; story 47 requires this matrix).

Status vocabulary: **present** (behaviour equal), **improved** (equal plus a security/performance/UX gain), **deliberately-excluded** (Owner exclusion or spec out-of-scope), **deferred** (known, recorded in an earlier ticket, not implemented), **missing** (reference has it, Waycraft does not, no recorded exclusion = GAP), **unproven** (implemented, no behavioural test; flagged in the Evidence column).

All "evidence" below is a fixture/harness test (host routes with temp dirs, 127.0.0.1 catalog stubs, local git fixtures, `react-test-renderer` against the assembled `dist/client.js`). Nothing here proves the installed DSH desktop, real browser focus/RTL layout, live ClawHub / skills.sh / GitHub, a paired host or crash durability. See "Not proven" at the end and `docs/ai/ticket-157-owner-test.md`.

Line numbers are for the #157 base tree. Test references are `file:line` of the `test(...)` declaration in `test/`.
