## Diagnosis

A permanent refresh rejection can persist reauthentication-required account state while the native RPC returns a sanitized error. The browser retained connected metadata when its abort deadline fired. In addition, ordinary status is not passive: native status decorates the account snapshot with runtime.snapshot(), whose available()/listModels() paths can discover catalogs and acquire account sessions, potentially causing grants. It is not safe error reconciliation.

## Candidate contract

The existing public native RPC accepts `{ action: 'status', mode: 'passive' }`. Only this literal optional mode on status is admitted; other values, extra fields and mode on other actions reject. It returns the existing account service snapshot and runtime availability/enabled flags but never calls runtime.snapshot() or includes a runtime catalog. Normal explicit status retains its existing behavior.

A failed explicit refresh immediately clears runtime controls and marks retained account metadata non-actionable. Before the operation deadline it may make one passive status call using the same signal and deadline. The original sanitized operation error remains visible. On timeout, Promise.race settles even if transport ignores abort; mounted metadata fails closed and no aborted status requery is started. Late transport settlement cannot publish state. Controller identity fences old completions across cleanup/new requests. Unmount first removes publication authority, then aborts; an abort listener clears the owned timer and rejects a separate cancellation race, settling owned work without waiting for an uncooperative transport or deadline. Finally only clears the matching controller and never clears replacement busy state. Account settings require both an authoritative runtime snapshot and connected account state: a transient failure with a still-connected passive account cannot mount settings initialized from missing preferences. Explicit full status restores saved nondefault preferences. No credential grant is replayed by reconciliation.
